Câu 1: Phân biệt position: relative và position: absolute trong CSS

1. Position Relative

Position: relative dùng để định vị phần tử tương đối so với vị trí ban đầu của chính nó. Phần tử vẫn chiếm không gian trong bố cục trang web. 

.box1{
    position: relative;
    top: 20px;
    left: 20px;
}

Khi sử dụng thuộc tính trên, phần tử sẽ dịch chuyển xuống 20px và sang phải 20px so với vị trí gốc.

2. Position Absolute

Position: absolute dùng để định vị phần tử theo phần tử cha gần nhất có thuộc tính position khác static. Phần tử sẽ bị tách khỏi luồng tài liệu HTML. 

.container{
    position: relative;
}

.box2{
    position: absolute;
    top: 10px;
    right: 10px;
}

Phần tử box2 sẽ nằm ở góc trên bên phải của container.

3. So sánh

Relative Absolute
Giữ nguyên vị trí trong bố cục Tách khỏi bố cục
Dùng để điều chỉnh vị trí nhẹ Dùng để tạo menu, popup, nút nổi
Responsive tốt hơn Cần kiểm tra nhiều thiết bị

4. Ảnh hưởng đến Responsive Web

Relative thường phù hợp với thiết kế Responsive vì vẫn giữ cấu trúc bố cục. Absolute nếu sử dụng quá nhiều có thể gây lệch giao diện trên điện thoại hoặc màn hình nhỏ. Khi triển khai lên Hosting cần kiểm tra giao diện trên máy tính, máy tính bảng và điện thoại.

Câu 2: Quy trình đăng ký Domain và Hosting

1. Quy trình đăng ký

  1. Mua tên miền (Domain).
  2. Thuê dịch vụ Hosting.
  3. Trỏ DNS của Domain đến Hosting.
  4. Upload mã nguồn website.
  5. Kiểm tra hoạt động website.

2. DNS là gì?

DNS (Domain Name System) là hệ thống giúp chuyển đổi tên miền dễ nhớ thành địa chỉ IP của máy chủ lưu trữ website.

Ví dụ: 

www.google.com
↓
142.250.xxx.xxx

3. Công cụ triển khai miễn phí

  • GitHub Pages
  • Netlify
  • Vercel

4. Rủi ro bảo mật

  • Cấu hình DNS sai dẫn đến website không hoạt động.
  • Không bật HTTPS gây mất an toàn dữ liệu.
  • Cấu hình quyền truy cập sai.
  • Lộ thông tin tài khoản Hosting.
  • Không sử dụng mật khẩu mạnh.

Câu 3: So sánh let, const và var trong JavaScript

1. Bảng so sánh

Từ khóa Scope Hoisting Cho phép gán lại
var Function Scope Có Có
let Block Scope Có Có
const Block Scope Có Không

2. Ví dụ var

console.log(a);

var a = 10;

Kết quả: 

undefined

Do var được hoisting lên đầu.

3. Ví dụ let

console.log(b);

let b = 20;

Kết quả: 

ReferenceError

Do let nằm trong Temporal Dead Zone.

4. Ví dụ const

const PI = 3.14;

PI = 4;

Kết quả: 

TypeError

5. Gỡ lỗi bằng Chrome DevTools

  • Mở DevTools bằng phím F12.
  • Xem lỗi trong tab Console.
  • Sử dụng Breakpoint trong tab Sources.
  • Kiểm tra Network để theo dõi tài nguyên tải về.
  • Theo dõi giá trị biến trong quá trình chạy.

Câu 4: Event Delegation trong JavaScript

1. Khái niệm

Event Delegation là kỹ thuật gắn một sự kiện lên phần tử cha thay vì gắn riêng cho từng phần tử con.

Sự kiện được truyền từ phần tử con lên phần tử cha thông qua Bubbling.

2. Ví dụ

HTML: 
    
    
  • Sản phẩm 1
    • 
    
  • Sản phẩm 2
    •
JavaScript: 
document.getElementById("list")
.addEventListener("click", function(e){

    if(e.target.tagName === "LI"){
        alert(e.target.innerText);
    }

});

Khi click vào bất kỳ thẻ li nào, sự kiện sẽ được xử lý bởi ul.

3. Ứng dụng trong danh sách động

Khi JavaScript thêm mới các phần tử li sau khi trang đã tải, chúng vẫn có thể sử dụng sự kiện click mà không cần gắn lại Event Listener.

4. Lợi ích

  • Tiết kiệm bộ nhớ.
  • Giảm số lượng Event Listener.
  • Tăng hiệu năng website.
  • Dễ bảo trì và mở rộng.
  • Hoạt động tốt với dữ liệu động.

5. Kết hợp với HTML/CSS

Khi kết hợp Event Delegation với HTML và CSS, website sẽ xử lý sự kiện hiệu quả hơn, tải nhanh hơn và phù hợp với các ứng dụng Web hiện đại như giỏ hàng, danh sách sản phẩm, bình luận và mạng xã hội.
